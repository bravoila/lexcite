## 本次解析与回归样例

- “依照本法”换行后接“第一百四十一条的规定”：仍归属前一条，不误报重复。
- “第X条第二款”“第X条规定的”“第X条、第Y条”“第X条至第Y条”以及再次换行的“的规定”：保留引用。
- 引用一个未单独出现的条号，不因此创建虚假法条记录。
- 同时支持独立一行的条号与无空格的紧凑标题。
- “第二章规定的……”不被误当章节标题截掉。
- 真正重复的中文/阿拉伯数字条号，仍提示两处行号和片段，不静默覆盖。
- 明确标记的后附起草说明从法条结果中排除，预览显示排除位置；没有声称能自动识别所有说明、附录或页面结构。
- 单独正文即可预览；真正保存仍要求完整法规元信息和合法来源字段。
- 1.0.0旧库增加来源字段后，原条文、来源、复核记录和配置保留；历史引用兼容导出。
- 无链接文件仍需人工复核才参与回答，引用和导出不伪造官网网址。
- URL边界测试覆盖非官方域名、私网DNS、重定向、下载大小与TLS原主机名校验。

## 如何复现

后端与DOM测试：

```bash
pip install -r requirements-dev.txt
python -m pytest -q
npm ci
python scripts/test_ui.py
```

可选真实浏览器测试（只用于开发验证，生产不需要Node或浏览器）：

```bash
npm install --no-save --package-lock=false playwright@1.62.1
npx playwright install chromium
python scripts/test_browser.py
```

脚本会启动临时服务与测试数据库，并在完成后清理。浏览器脚本默认输出到 `test-results/browser/`；可用 `LEXCITE_BROWSER_OUTPUT` 指定其他目录。`tests/browser_fixture_app.py` 仅是测试入口，不能替代生产的 `app.main:app`。

1. **用户原始资料**：当前只收到局部截图，没有完整文件或实际法规网址。已用相同类型断行和交叉引用样例回归，未声称复现完整原文件；复杂OCR、特殊引文排版仍可能需要人工调整。
2. **实际官网访问**：当前环境直接读取一个政府站点时DNS解析失败；真实官网下载未标为通过。部署服务器的DNS、网络、证书和官网限制会影响结果；动态网页、扫描件或特殊压缩响应也可能无法读取。失败原因应显示在弹窗内，不自动当成成功导入。
3. **真实模型与法律能力**：没有使用国产API密钥或本地模型权重做业务效果评测。Qwen、DeepSeek等模型的准确性、拒答率与成本需在目标环境实测。
4. **Docker、GPU与多浏览器**：没有可用Docker引擎；未做镜像构建、GPU、Safari或Firefox验收。此次真实浏览器覆盖指定Chromium版本与尺寸，不代表全部浏览器可访问性验收。
5. **法库与规模**：默认法库为空，演示数据仅3条。没有全量法库、自动法规更新、组织权限和大并发验收。
