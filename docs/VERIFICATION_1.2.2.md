## 本次关键证据

- `《刑法》`、`《《中华人民共和国刑法》》`等输入去除最外层成对书名号；法规正式名称内部对另一法律的引用保留。原有本地名称匹配本身已忽略书名号，本次还修复公开检索词、研究计划、显示与导出。
- 合成刑法文件从第一条至第四百五十二条，并含一条测试“条之一”。模拟读取全文和独立修正案日期后，准确召回第十五条与第二百三十三条，并生成可打开的两项引用。没有搜索密钥也不会调用搜索API。
- 主全文与主日期来源均失败时，官方备用入口可继续；四次读取预算同时计算失败尝试和日期核对。
- 遗漏主条号、旧修正案、目录未知的新修正案、错误日期/来源，以及基准日期早于整编版本施行日期，均不纳入临时证据。
- 未配置搜索、两次搜索用完、四次读取用完、时限不足、搜索HTTP错误分别输出具体原因。目录失效时，可在已配置服务下搜索回退，同一规范不重复无效尝试。
- 界面缺口直接显示联网原因并提供配置入口；引用弹窗和导出包含独立日期依据。模拟旧记录已带书名号时，刷新后也不会重复包裹。

## 官方地址核查与实际网络边界

通过网页检索工具核查了国家税务总局的刑法整编页面、天津税务转载页面及修正案官方公布/转载信息。刑法整编页注明修正案（十二），同时附则保留原法1997年施行文字，因此没有用该旧日期冒充整编版本日期。

开发执行环境使用生产读取器直连国家税务总局与天津税务两个地址时，均返回“无法解析官网地址”。浏览器测试中下载为合成响应；没有声称本机或用户服务器已经真实联网读取成功。用户部署后须验证其DNS、HTTPS和官网访问限制。最高检主日期页面在网页工具打开时也未成功，已提供经网页工具读取的检察机关备用转载入口。

来源目录和版本元信息位于 `app/authorities.py`，当前仅四份文件，不是持续更新的全国法库。主条号完整性不证明每项增补条文和后续修法均已穷尽；法律适用、版本与效力仍须人工核对。

未构建Docker镜像、未修改用户服务器、未用真实千问/DeepSeek/Ollama执行法律效果验收。旧版本验证记录分别保留，不能当作本次重复执行。pytest有一条Starlette/httpx弃用提示，不影响通过。

## 复现

安装项目开发依赖及Playwright/Chromium后，在项目目录运行：

```bash
python -m pytest -q
python scripts/test_ui.py
LEXCITE_BROWSER_SCRIPT=tests/browser_sources.cjs python scripts/test_browser.py
LEXCITE_BROWSER_SCRIPT=tests/browser_core.cjs python scripts/test_browser.py
LEXCITE_BROWSER_SCRIPT=tests/browser_layout.cjs python scripts/test_browser.py
LEXCITE_BROWSER_SCRIPT=tests/browser_agent.cjs LEXCITE_GUIDE_PATH="$PWD/docs/LexCite_Step_by_Step_Guide.html" python scripts/test_browser.py
```

环境变量写法适用于macOS/Linux。测试入口只用于临时数据；生产入口仍为 `app.main:app`。
