# 升级到 1.2.2：法源名称与刑法联网补查

1. 停止正在进行的研究，并备份原配置与数据。保留 `.env`、`data`、`secret.key`、原 Compose 项目名及数据卷。
2. 在原项目目录用升级包更新应用代码、静态资源和文档。从 1.2.1 升级不需要迁移数据库、重新初始化或重新导入法规。
3. 原目录执行 `docker compose up -d --build`。使用多个 Compose 文件的部署继续沿用原文件与参数；原生 Python 部署则重启原服务。
4. 强制刷新浏览器，确认左下角及 `/healthz` 均为 **1.2.2**。不要只覆盖 `static`，前后端版本必须一致。
5. 在原案件选择“联网补齐官方法源”并重新提问。刑法现在进入内置目录；旧对话的双书名号会修正显示，但旧失败回答不会事后自动变成成功回答。
6. 目录外法源仍需配置搜索服务。看到“尚未配置搜索服务”时，点击“配置联网搜索”，选择博查或自建 SearXNG，保存并测试后重试。聊天模型密钥与搜索服务配置是两回事。

本次内置目录为四份文件，并非全国法库。刑法目录只覆盖所列整编版本；基准日期早于该版本施行日期时，需导入当时适用的版本。官网访问失败、页面不完整或版本核对失败时，具体原因会显示，程序仍不会生成无依据的结论。

请保留原数据卷，不要运行 `docker compose down -v`。本次未操作你的服务器；完成上述更新后才生效。
