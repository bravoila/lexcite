# 教程结构更新 · 2026-09-28

第3A章“国产模型API”和第3B章“本地Ollama与重排服务”均按三个配置标签组织：分析模型、Embedding、Rerank。云端分析保留阿里、DeepSeek、硅基流动三个厂商标签；向量和重排各自选择阿里或硅基，也可跳转搭配本地服务。

目录移除单列的DeepSeek入口，改为两条路线各三个配置入口。旧 `#deepseek` 链接仍能展开对应标签。第7章只保留索引建立、实际检索检查、评测与日常维护。

本地配置保留B1全容器、B2宿主机Ollama、B3宿主机法据三种布局，分别给出分析、向量、重排的正确地址。新增 `compose.reranker.host.yaml`，供B3只启动重排容器并绑定 `127.0.0.1:8081`。默认B1/B2不需要该覆盖文件。
