# 升级到 1.2.1：紧凑的案件研究界面

本次主要修改界面排版和输入框交互。从 1.2.0 升级不需要迁移数据库或重新导入法规。

1. 停止正在进行的研究，备份现有数据。在原项目目录更新代码，保留原 `.env`、`data` 目录、`secret.key` 和 Docker 数据卷。继续沿用原 Compose 项目名。
2. 将升级包中的新版文件覆盖到原项目。请同时更新应用代码和 `static` 静态资源，避免前后端版本混用。
3. 在原项目目录执行 `docker compose up -d --build`。若原来使用 Ollama 或 GPU 的多个 Compose 文件，沿用原来的文件和启动参数，增加 `--build`。直接用 Python 部署时，更新后重启原服务。
4. 刷新浏览器，左下角与 `/healthz` 应显示 **1.2.1**。仍显示旧版时，Windows/Linux 按 Ctrl + Shift + R，macOS 按 Command + Shift + R。若使用反向代理缓存，还需更新该缓存。
5. 打开原案件：确认标题区变为紧凑排列；提问框空白时为一行；切换法源范围时，下方说明完整显示。输入多行内容后，输入框会增高，到达高度上限后在框内滚动。

从 1.1.x 或更早版本升级，还请阅读 [1.2.0 的核心流程变化](UPGRADE_1.2.0.md)，尤其是法规标准名称和在线临时法源的使用方式。

不要执行 `docker compose down -v`。如果升级后出现首次初始化页，请先核对项目名和数据目录是否沿用原配置，避免在错误的数据目录重新初始化。

## 界面变化

- 删除研究页重复的“法律研究”标题，案件名称、日期与地区紧凑排列；长名称可通过“案件信息”查看和修改。
- 法源说明在下拉控件下方独立排版，并随“沿用设置 / 仅本地 / 联网”切换。
- 问题框默认一行，随内容自动增长；长文本滚动显示，发送后恢复紧凑高度。
- 法源范围、回答方式、开始按钮合并为工具栏；窄屏自动换行。
- 公开检索词默认折叠，展开后仍可收起。桌面回答区使用剩余视口高度，答案与案件记忆分别滚动。
- 同步校正设置页的模型调用次数说明，使之与核心流程的最多18次上限一致。

本次没有操作你的现有服务器，部署更新后才会看到新版。
